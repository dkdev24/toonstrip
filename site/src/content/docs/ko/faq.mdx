## toonstrip이 코믹을 대신 생성해 주나요?

아니요, 앞으로도 그럴 일은 없습니다. toonstrip은 사용자가 건네준 문서를 렌더링할
뿐입니다. 대사를 쓰고, 감정과 카메라를 정하고, 무엇이 재미있을지 판단하는 일은 작성자
본인의 몫이거나, 스크립트의 몫이거나, 원한다면 언어 모델의 몫일 수도 있습니다. 무엇이
JSON을 만들어 내든 그 과정은 이 라이브러리 바깥에 있습니다. 이 사이트의 플레이그라운드는
에디터이지 생성기가 아닙니다.

## 텍스트에서 감정을 추론해 주는 기능이 있나요?

없습니다. Comic Chat은 입력한 단어에서 기분을 추측했지만, toonstrip은 텍스트를 읽지
않습니다. `emotion`은 body마다 직접 설정합니다. 추론 기능이 필요하다면 toonstrip
앞단에 직접 구현하고, 그 결과를 문서에 써넣으면 됩니다.

## 게임 엔진이나 채팅 클라이언트인가요?

아닙니다. 세션도, 턴도, 이벤트 스트림도 없습니다. 패널은 그저 작성된 데이터입니다.
toonstrip은 원래 게임을 가진 프로젝트에서 추출되어 나왔고, 게임 부분은 그 프로젝트에
그대로 남았습니다.

## 라이선스는 무엇이고, 캐릭터를 상업적으로 사용할 수 있나요?

코드는 MIT입니다. 기본 팩의 아트는 Microsoft의 저작권 표시를 그대로 유지한 채 MIT로
재배포되는 Microsoft Comic Chat 아트입니다. 자세한 내용은 레포의 `NOTICE`를 참고하시기
바랍니다. MIT는 상업적 사용을 허용합니다. COMIC CHAT은 Microsoft의 상표이며 이
프로젝트는 Microsoft와 아무 관련이 없으므로, 제품 이름을 여기서 따오지 않아야 합니다.
직접 만드는 팩은 각 `pack.json`에 명시한 라이선스를 따릅니다.

## 어떤 브라우저를 지원하나요?

Canvas 2D, 커스텀 엘리먼트, `ResizeObserver`, `IntersectionObserver`를 지원하는
브라우저라면 어디서든 동작합니다. 현재의 모든 주요 브라우저가 여기에 해당하며,
폴리필은 포함되어 있지 않습니다.

## 서버에서도 렌더링되나요?

Astro 컴포넌트에서는 그렇지 않습니다. 서버는 비활성 상태의 태그만 출력하고, 실제
그리기는 브라우저가 담당합니다. 정적 PNG(오픈 그래프 이미지, RSS, `<noscript>`
대체 콘텐츠)가 필요하다면, Node에서 동일한 렌더러를 실행하는 CLI를 사용하시기
바랍니다.

```
npx -p @toonstrip/cli toonstrip render strip.json --out strip.png --width 1200
```

## Astro 없이도 쓸 수 있나요?

네. 커스텀 엘리먼트에는 프레임워크 의존성이 없습니다. [Plain HTML](/docs/plain-html/)을
참고하시기 바랍니다. Astro가 일급 래퍼로 제공되는 이유는 작성자 본인이 그것을 쓰기
때문일 뿐입니다. 다른 프레임워크용 래퍼도 각각 몇 줄이면 만들 수 있습니다.

## 용량은 얼마나 되나요?

엘리먼트와 코어, 스키마 검증기를 합치면 gzip 기준 약 36 KB입니다(배포된 빌드 기준 실측).
스프라이트 시트는 문서에서 실제로 쓰인 캐릭터별로만 받아오므로, 캐릭터 세 명짜리
스트립이라면 팩 전체가 아니라 시트 세 장과 배경 하나만 로드됩니다.

## 한글(또는 그 외 비라틴 문자) 텍스트가 왜 이상하게 보이나요?

말풍선 텍스트는 캔버스 위에 Comic Sans로 그려지는데, 이 폰트에는 한글이 없어서
해당 글리프는 폰트 스택의 다음 순서로 넘어갑니다. 우선 Noto Sans KR, 그다음 플랫폼의
한글 산세리프 서체(Apple SD Gothic Neo, 맑은 고딕) 순서입니다. `@toonstrip/core` 0.1.7
이전에는 스택에 한글 서체가 아예 지정되어 있지 않아, Windows에서는 궁서체(붓글씨체)로
떨어졌습니다. 어디서나 Noto Sans KR이 쓰이게 하려면 페이지에 직접 선언해야 하며(이
사이트는 Astro의 fonts API에서 `korean` 서브셋을 사용합니다), 엘리먼트는
`document.fonts`를 기다렸다가 그리고, 서체가 늦게 도착하면 다시 그립니다.
`toonstrip render`에는 `--font NotoSansKR-Regular.ttf`를 넘기면 됩니다.

## 아트가 왜 흑백인가요?

원본 Comic Chat 아트가 흑백이기 때문입니다. 팩 자체는 컬러로 만들 수 있으며,
렌더러의 어떤 부분도 흑백을 전제로 하지 않습니다.

## AI 에이전트가 대신 문서를 작성해 줄 수 있나요?

toonstrip 자체는 여전히 콘텐츠를 생성하지 않지만(맨 위 질문 참고), 코딩 에이전트에게
문서 형식과 감정 휠 각도, 실제 캐릭터/배경 id를 가르쳐 주는
[에이전트 스킬](/docs/agent-skill/)이 있습니다. 이를 이용하면 에이전트가 더 이상
추측에 의존하지 않고, 결과를 넘기기 전에 직접 검증하게 됩니다.

## 버그를 신고하거나 캐릭터를 기여하려면 어디로 가야 하나요?

[GitHub issues](https://github.com/dkdev24/toonstrip/issues)를 이용하시기 바랍니다.
캐릭터를 추가하려면 [에셋 팩](/docs/asset-packs/)을 읽고 `pack-example`이나 본인의
팩 레포에 풀 리퀘스트를 열면 됩니다.
