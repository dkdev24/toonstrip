toonstrip는 사용자가 제공한 데이터로 코믹 스트립을 렌더링합니다. 별도로 생성할 것도, 이미지
파이프라인도 없습니다. 작은 JSON 문서를 작성하면 페이지가 이를 캔버스에 그립니다. 이 페이지는
빈 HTML 파일에서 시작해 첫 패널을 렌더링하기까지의 과정을 안내합니다. 설치도, 빌드 단계도
필요 없습니다.

## 1. 엘리먼트 추가하기

`@toonstrip/element`는 프레임워크에 의존하지 않는 커스텀 엘리먼트입니다.
[esm.sh](https://esm.sh)가 이 패키지와 그 의존성을 대신 resolve해 주므로,
`<script type="module">`에서 바로 가져올 수 있습니다.

```html
<script type="module">
  import "https://esm.sh/@toonstrip/element@0.1.11";
</script>
```

다른 의존성과 마찬가지로 정확한 버전을 고정하세요.

## 2. 팩 지정하기

기본 팩은 15개 캐릭터와 배경 3종으로 구성된 Comic Chat 로스터입니다. unpkg가 팩 파일
(`pack.json`, 스프라이트 시트, 배경)을 CORS가 활성화된 상태로 그대로 서빙하므로, 어디에도
복사할 필요가 없습니다.

```js
strip.packs = ["https://unpkg.com/@toonstrip/pack-comic-chat@0.1.1/"];
```

## 3. 스트립 렌더링

페이지에 `<comic-strip>` 태그를 두고 `document` 프로퍼티를 설정합니다.

```html
<comic-strip id="strip"></comic-strip>

<script type="module">
  import "https://esm.sh/@toonstrip/element@0.1.11";

  const strip = document.getElementById("strip");
  strip.packs = ["https://unpkg.com/@toonstrip/pack-comic-chat@0.1.1/"];
  strip.document = {
    version: 1,
    panels: [
      {
        backdrop: "field",
        camera: "medium",
        bodies: [{ character: "anna", emotion: { angle: 0, intensity: 0.6 } }],
        speakers: [{ speaker: "anna", balloon: "speech", text: "My first strip." }],
      },
    ],
  };
</script>
```

<CodeAndStrip doc={firstStrip} title="strip.json" layout="side" />

임베드에 필요한 것은 이 세 가지, 스크립트 태그와 팩 URL, 문서뿐입니다. `index.html`로 저장하고
서버 없이 그대로 열어보세요.

<Callout kind="tip" title="로컬에 설치하고 싶다면">
`npm install @toonstrip/element @toonstrip/pack-comic-chat`도 가능하지만, bare 형태의
`import "@toonstrip/element"`는 번들러나 import map을 거쳐야만 브라우저에서 resolve됩니다.
일반 `<script type="module">` 단독으로는 처리할 수 없습니다. 번들러 연동과 팩을 직접 정적
파일로 서빙하는 방법은 [Plain HTML](/docs/plain-html/)을 참고하세요.
</Callout>
