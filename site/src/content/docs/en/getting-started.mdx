toonstrip renders a comic strip from data you supply. There is nothing to generate and no
image pipeline: you write a small JSON document, the page draws it on canvases. This page
gets you from an empty HTML file to a rendered panel, no install and no build step.

## 1. Add the element

`@toonstrip/element` is a custom element with no framework dependency.
[esm.sh](https://esm.sh) resolves it and its dependencies for you, straight from a
`<script type="module">`:

```html
<script type="module">
  import "https://esm.sh/@toonstrip/element@0.1.11";
</script>
```

Pin the exact version, same as any other dependency.

## 2. Point it at a pack

The default pack is the fifteen-character Comic Chat roster with three backdrops. unpkg
serves a pack's files (`pack.json`, sprite sheets, backdrops) as-is, with CORS enabled, so
there is nothing to copy anywhere:

```js
strip.packs = ["https://unpkg.com/@toonstrip/pack-comic-chat@0.1.1/"];
```

## 3. Render a strip

Put a `<comic-strip>` tag in the page and set its `document` property.

```html
<comic-strip id="strip"></comic-strip>

<script type="module">
  import "https://esm.sh/@toonstrip/element@0.1.11";

  const strip = document.getElementById("strip");
  strip.packs = ["https://unpkg.com/@toonstrip/pack-comic-chat@0.1.1/"];
  strip.document = {
    version: 1,
    panels: [
      {
        backdrop: "field",
        camera: "medium",
        bodies: [{ character: "anna", emotion: { angle: 0, intensity: 0.6 } }],
        speakers: [{ speaker: "anna", balloon: "speech", text: "My first strip." }],
      },
    ],
  };
</script>
```

That is the whole embed: a script tag, a pack URL, and a document. Save it as `index.html`
and open it, no server required.

<Callout kind="tip" title="Installing locally instead?">
`npm install @toonstrip/element @toonstrip/pack-comic-chat` works too, but a bare
`import "@toonstrip/element"` only resolves in a browser through a bundler or an import
map — a plain `<script type="module">` cannot do it alone. See [Plain HTML](/docs/plain-html/)
for wiring it into a bundler and serving a pack from your own static files.
</Callout>
